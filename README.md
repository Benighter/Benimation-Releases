# Benimation downloads

Signed Android APKs, checksums and update metadata for Benimation. Application source is maintained privately at https://github.com/Benighter/Benimation.

Download the latest APK from Releases. Android asks you to approve installation. Future versions are offered inside the app, with checksum, package and signing-certificate checks.

This repository contains release artifacts and user-facing release information only. It does not contain application source or signing keys.
